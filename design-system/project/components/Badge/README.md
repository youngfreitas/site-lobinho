# Badge

Uma ou duas palavras em caixa alta para destacar um passeio ou mostrar seu estado.

- **ceu** (padrão) — informação neutra: "Família", "Com mergulho".
- **lancha** / **marinho** — destaque de marca: "Mais procurado", "Novo".
- **sucesso** — "Vagas abertas". **alerta** — "Últimas vagas", "Mar agitado". **erro** — "Esgotado", "Cancelado".
- No máximo um selo de destaque por cartão. Estados (sucesso, alerta, erro) só quando forem verdade agora.
- Texto em estilo `rotulo`: 12px, negrito, caixa alta, espaçado.
